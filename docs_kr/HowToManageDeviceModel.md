# SmartThings Things 장치 모델을 관리하는 방법  
이 문서에서는 장치 모델을 가져오고 내보내는 방법을 설명합니다.

## 장치 모델 가져오기
1. **Device/Platform** 도구 모음에서 **Import**를 클릭합니다.  
![JSON 파일 가져오기](../docs/media/rt_model_import_model.png)
2. 가져올 장치 모델이 포함된 JSON 파일을 선택하고 **OK**를 클릭합니다.  
![JSON 파일을 선택하세요.](../docs/media/rt_model_import_model_window.png)
3. 가져온 장치는 장치 목록에 **Custom** 유형으로 표시됩니다.  
![가져온 장치가 나타납니다](../docs/media/rt_model_import_model_finished.png)  

## 장치 모델 내보내기
1. 내보낼 모델을 선택하고 **Device/Platform** 도구 모음에서 **Export**를 클릭합니다.  
![모델 내보내기](../docs/media/rt_model_export_model.png)  
2. 장치 모델이 JSON 파일로 내보내집니다. 내보낸 모델의 파일 ​​이름을 입력하고 **OK**를 클릭합니다.  
![JSON 파일로 내보냈습니다.](../docs/media/rt_model_export_model_window.png)
