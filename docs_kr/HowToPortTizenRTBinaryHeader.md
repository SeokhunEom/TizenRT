## 바이너리 헤더 정보

		 -----------------------------------------------------------------------------------------------
		| CRC32 | 헤더 크기 | 바이너리 버전 | 바이너리 크기 | 보안 헤더 크기 | 보안 헤더 |
		|(4바이트) |(2바이트) |(4바이트) |(4바이트) |(2바이트) |(#바이트) |
		 -----------------------------------------------------------------------------------------------

이러한 바이너리 헤더 구성 요소는 다음과 같습니다.

### 1. CRC32
모든 헤더와 실제 TizenRT 바이너리에 대한 CRC32 값입니다. Header 크기부터 바이너리 끝까지 전체 바이너리에 대한 체크섬 값입니다. uint32_t 유형이고 크기는 4바이트입니다.

### 2. 헤더 크기
CRC32를 제외한 헤더 전체 데이터 크기입니다. uint16_t 유형이고 크기는 2바이트입니다.

### 3. 바이너리 버전
"YYMMDD" 형식(CONFIG_BOARD_BUILD_DATE)의 바이너리 버전입니다. uint32_t 유형이고 크기는 4바이트입니다.

### 4. 바이너리 크기
바이너리의 헤더 크기를 제외한 실제 TizenRT 바이너리 크기입니다. uint32_t 유형이고 크기는 4바이트입니다.

### 5. 보안 헤더 크기
보안 헤더의 크기이며 보드에 따라 다릅니다. uint16_t 유형이고 크기는 2바이트입니다.

### 6. 보안 헤더
이것은 보안 헤더 서명입니다. 숯형이며 고정방법에 따라 크기가 달라질 수 있습니다.  
참고: 보안 헤더 및 전체 바이너리의 크기는 향후 보안 방법에 따라 달라질 수 있습니다.

<a id="how-to-add-binary-header"></a>
## 바이너리 헤더 추가 방법

사용자는 아래와 같이 build/configs/`<board>`/Make.defs에서 바이너리 헤더 지원을 위해 MAKE_SAMSUNG_HEADER를 정의해야 합니다.

```
SECURE_HEADER_SIZE=xx

define MAKE_SAMSUNG_HEADER
  $(TOPDIR)/../os/tools/mksamsungheader.py $(1) kernel ${SECURE_HEADER_SIZE}
endef
```
이 매개변수는 다음과 같습니다:

1. `$(1)`는 소스 바이너리 확장입니다. `mksamsungheader.py`에서 소스 바이너리 경로를 import하는데 사용되므로 그대로 채워주어야 합니다.
2. `${SECURE_HEADER_SIZE}`는 보안 헤더의 크기입니다. 보드 부트로더에 따라 크기를 설정합니다.


`MAKE_SAMSUNG_HEADER`는 `MAKE_BOARD_SPECIFIC_BIN` 다음에 호출됩니다. 바이너리 이름은 `MAKE_BOARD_SPECIFIC_BIN`에서 변경할 수 있습니다. 그래서 우리는 `board_metadata.txt`를 사용하여 커널 바이너리 이름을 관리합니다. `mksamsungheader.py`는 board_metadata.txt에서 커널 바이너리 이름을 가져옵니다.

예를 들어, rtl8721csm 보드의 `board_metadata.txt`는 아래와 같습니다.
```
KERNEL="km0_km4_image2"
```
